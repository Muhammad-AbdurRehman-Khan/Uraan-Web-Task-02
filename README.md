Open `index.html` in your browser to view the page.

## 📌 Project Overview
This project contains the complete HTML5 and CSS3 solution for **Task 02**, converting the high-fidelity UI design (`design.jpg`) for the **Catchub** mobile app landing page into a clean, semantic, and fully responsive web page.

---

## 🎨 Design & Layout Details
The landing page accurately recreates all five sections from the reference mockup:

1. **Hero / Header Section**:
   - Catchub script logo
   - Headline: `WATCH. COMMUNICATE. CREATE.`
   - Subtitle: `Everything you need to socialise`
   - Store download badges for Android & iOS with interactive hover micro-interactions
   - High-resolution three-screen mobile showcase (`top_screens.png`)

2. **Channels Section**:
   - Showcase of channel features (`sec_screens.png`)
   - `CHANNELS` heading with letter-spacing and typography matching the design
   - Three-line descriptive copy

3. **Messages Section**:
   - Alternating layout displaying `MESSAGES` copy on the left
   - Messaging UI screens (`thhh_screens.png`) on the right

4. **In Future Section**:
   - Feature exploration mockup (`for_screens.png`) on the left
   - Category navigation icons row (`vectors.png`) featuring Foods, Events, Party, Metro, Jobs, Housing, and Places
   - `IN FUTURE` title and description

5. **Footer / Download CTA**:
   - "For download click here:" prompt
   - Centered Android and Apple Store badges
   - Interactive "CONTACT US" link
   - Peratude company branding mark (`peratude.png`)

---

## 🛠️ Key Technical Highlights
- **Semantic HTML5**: Structured with proper semantic tags (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`, `<a>`, `<p>`, `<h1>`, `<h2>`).
- **Responsive Flexbox Architecture**: Alternating two-column layouts on desktop transitioning smoothly to centered stacked layouts on tablet and mobile viewports.
- **Clean CSS3**: Styled without third-party frameworks, using custom properties (CSS variables), fluid media queries, and GPU-accelerated hover transitions.
- **Typography**: Google Font **Poppins** loaded with optimal font weights (`300`, `400`, `500`, `600`, `700`, `800`) to match the mockup's visual weights.
